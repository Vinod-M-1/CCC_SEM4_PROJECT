# Coin Change Visualizer

A clean, modern, and professional web dashboard to visualize the **Coin Change Problem** using two different approaches: the **Greedy Algorithm** and **Dynamic Programming (DP)**.

## Features
- **Interactive Visualizations**: Step-by-step animations of algorithm execution.
- **Algorithm Comparison**: See the difference between Greedy (which may not always yield optimal results) and Dynamic Programming (guaranteed optimal).
- **Responsive Design**: Professional dashboard UI optimized for desktop, tablet, and mobile viewing.
- **Customization**: Set custom target amounts and coin denominations.
- **Speed Control**: Adjustable execution speed for better comprehension.

## Technologies Used
- HTML5
- CSS3 (Clean Dashboard Design, Flexbox/Grid, Animations)
- Vanilla JavaScript (DOM manipulation, async/await for visual delays)

## How to Run
Simply open the `index.html` file in any modern web browser. No server or additional dependencies are required.

## Structure
- `index.html`: Main layout and UI structure.
- `style.css`: Modern, product-level CSS styling (responsive).
- `script.js`: Algorithm implementations and DOM manipulation logic.
- `coinchange.cpp`: Reference implementation of the algorithm in C++.

## Usage
1. Enter your desired **Target Amount**.
2. Enter comma-separated **Coin Denominations** (e.g., 1, 5, 10, 25).
3. Adjust the visualization speed using the slider.
4. Click either **Run Greedy** or **Run DP** to visualize the process!
